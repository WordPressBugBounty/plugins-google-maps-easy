== Description ==

**Easy Google Maps by Supsystic** adds interactive Google Maps to any WordPress page: unlimited maps and markers, custom marker icons, marker categories with a filter, clustering and map themes. Describe every location with text, photos, video, links, phone and e-mail, then publish the map with a block, an Elementor widget or a shortcode. No code required.

The plugin works with your own Google Maps API key, and the settings page walks you through getting one in a couple of minutes. It supports the current Google Maps JavaScript API, including Cloud Map IDs and Advanced Markers.

= Unlimited maps and markers =

* Markers with text, photos, video, links, phone and e-mail
* Custom marker icons from the built-in library or your own image
* Marker categories with a front-end filter
* Marker clustering for maps with many locations
* Linked markers that open any URL on click
* Address search: type an address and get the pin

= Map settings =

* Roadmap, satellite, hybrid and terrain map types
* Width, height, zoom, minimum and maximum zoom
* Scroll-wheel and drag behaviour
* Responsive maps with a separate zoom level on mobile
* A starter set of map themes
* Map language and region (US, CA, GB, DE and more), so labels and address search match your country
* Google Maps China endpoint (maps.google.cn)

= Add maps anywhere =

* Gutenberg block, Elementor widget, sidebar widget, shortcode and PHP snippet
* Works with WPBakery, Divi, Beaver Builder and other page builders through the shortcode

= Import and export =

Move maps and markers between sites with CSV import and export.

* Get Direction button, routes with turn-by-turn steps and alternate routes, starting from the visitor's position

== Installation ==

1. In your dashboard go to Plugins → Add New Plugin and search for "Easy Google Maps".
2. Click Install Now, then Activate.
3. Open the Easy Google Maps settings and add your Google Maps API key. It takes a couple of minutes; a step-by-step guide is linked under Learn more.
4. Add a new map, then add markers by typing an address or clicking on the map, and save.
5. Add the map to a page with the block, the Elementor widget or the shortcode.

== Frequently Asked Questions ==

= Do I need a Google Maps API key? =

Yes. Google requires an API key to display its maps. It takes a couple of minutes to create one; a step-by-step guide is linked under Learn more.

= Does Google charge for maps? =

Google Maps Platform includes free monthly usage, and many small sites stay within it. Check Google's current pricing for your expected traffic.

= Does it support Cloud Map IDs and Advanced Markers? =

Yes. Add your Map ID in the map settings and markers render as Advanced Markers. Maps without a Map ID keep working as before. When a Map ID is set, Google controls the map style through Cloud Styling.

= How many maps and markers can I add? =

As many as you need. Maps and markers are unlimited in the free plugin.

= Can I use my own marker icons? =

Yes. Choose an icon from the built-in library or upload your own image.

= Can visitors filter markers by category? =

Yes. Assign markers to categories and show a front-end filter on the map.

= Does it support marker clustering? =

Yes. Nearby markers group into clusters that open as visitors zoom in.

= How do I add a map to a page or post? =

Use the plugin's block in the block editor, the Elementor widget, the sidebar widget, or paste the map shortcode. A PHP snippet is available for theme templates.

= Can I show my map in another language or for China? =

Yes. Set the map language and region in the settings, and switch to the Google Maps China endpoint if your visitors are in mainland China.

= Can I build a route through several points? =

Yes, with Pro. Add waypoints with descriptions, pick the travel mode and choose whether Google optimises the order of stops for the shortest trip or keeps your order. The route follows the roads and shows turn-by-turn steps.

= Can I show directions to a location? =

Yes, with Pro: a Get Direction button on every marker, routes with turn-by-turn steps, alternate routes and a start from the visitor's current position.

= Can I move maps to another site? =

Yes. Export maps and markers to CSV and import them on the other site.

= Is there a version that works without Google? =

Yes. Ultimate Maps by Supsystic uses OpenStreetMap and Leaflet without a Google API key and can import your Easy Google Maps maps.

= How can I report a security issue? =

Please report security issues through the [Patchstack Vulnerability Disclosure Program](https://patchstack.com/database/vdp/9e5fb658-48d1-4923-a3c3-16c434266113). The Patchstack team validates and triages each report and notifies us.
